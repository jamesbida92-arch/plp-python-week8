PLP Python Week 8 Toolkit Plan

TOOLS

1. Number Guessing Game
The number guessing game lets the user guess a secret number and tells them whether their guess is too high or too low.

2. To-Do List
The to-do list lets the user add tasks, view tasks, and remove tasks while the program is running.

3. Simple Calculator
The calculator lets the user perform addition, subtraction, multiplication, and division.

4. Name Formatter
The name formatter asks for a person's name and displays it in a neat, friendly format.
